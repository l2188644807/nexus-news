## 🚀 启动与体验方式

### 方式 1：双击运行 (Windows)
在工作区目录下直接双击：
```
start.bat
```

### 方式 2：终端命令
```bash
cd d:\按键精灵\realtime-news-portal
node server.js
```

浏览器访问：
👉 **http://localhost:3000**

## 💡 专属亮点功能
1. **指定渠道直通一键过滤**：切换到任何一个分类（如“实时电竞”），上方立即出现「玩加电竞 / 兔玩网 / Dot Esports / HLTV / Esports Insider / Liquipedia」胶囊按钮，点击可精准只看该渠道的所有快讯！
2. **多模态混合抓取管道**：集成了「标准 RSS + 深度 XML 清洗 + Cheerio 结构化网页提取 + 权威信标高保真推流」，确保所有 72 个指定渠道均能保持通畅运行。
3. **毫秒级 SSE 实时广播**：各大渠道产生最新资讯时，前端时间流无缝自动推送，无需按 F5 手动刷新。
